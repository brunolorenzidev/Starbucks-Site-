# Starbucks Landing Page

Este projeto é uma **landing page** interativa para a marca **Starbucks**, desenvolvida utilizando **HTML**, **CSS** e **JavaScript**. A página apresenta uma animação e interação dinâmica para exibir diferentes imagens e cores de fundo, criando uma experiência visual atraente para os usuários.

## Tecnologias Utilizadas

- **HTML**: Estrutura da página.
- **CSS**: Estilização da página, incluindo layouts responsivos e animações.
- **JavaScript**: Interatividade para troca de imagens e cores dinâmicas.

## Funcionalidades

- **Troca de Imagem**: Ao clicar nas pequenas imagens do menu, a imagem principal (grande) da Starbucks é trocada dinamicamente.
- **Alteração de Cor de Fundo**: Cada imagem do menu tem uma cor associada, que é alterada no fundo ao clicar nas imagens.
- **Design Responsivo**: A página é projetada para ser visualmente agradável em diferentes tamanhos de tela, com destaque para o layout flexível e centralizado.

## Como Funciona

1. **Estrutura HTML**:
   A página é dividida em três principais seções:
   - **Cabeçalho**: Contém o logo da Starbucks e o título com a frase de impacto.
   - **Conteúdo**: Apresenta o texto informativo sobre a marca e a imagem principal, que muda com a interação do usuário.
   - **Menu**: Um conjunto de pequenas imagens (botões) que permitem ao usuário trocar a imagem principal e a cor de fundo.

2. **Interatividade com JavaScript**:
   - O **JavaScript** gerencia as interações, realizando as trocas de imagem (`trocaimagem()`) e alterando a cor de fundo do círculo com a função `trocacor()`.
